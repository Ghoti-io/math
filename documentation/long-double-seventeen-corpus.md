# Seventeen-family reference and gate contracts

The committed compact JSON contains 2017 independently generated raw input
cells across all 17 APIs and four layouts. 1294 cells carry outward numerical
intervals, two carry rigorous far-underflow witnesses, and 721 carry exact
identity, domain, pole, NaN, or far-overflow contracts. No candidate output
supplies an expected value. Directed MPFR at 4096 bits supplies ordinary
bounds; independent mpmath starts at 8192 bits, with additional precision for
full-range trigonometric reduction and refinement if agreement does not close.
The compact bounds retain 2304 relative bits, exceeding the worst DD population
spacing requirement. Both working exponent ranges and integer construction
sizes are bounded before conversion.

## Independently reconstructed inputs

The input registry is regenerated from format geometry and rational recipes,
not from manifest counts or answers. It includes signed zeros and infinities,
both NaN signs and signaling classes, malformed extended80/DD encodings,
ordinary values, all inverse domains/poles/endpoints, atan2 zero/infinity
quadrants, minimum subnormals, immediate neighbors of minimum normal values,
full-exponent trig inputs, DD remote tails, error tails, gamma factorials and
near-pole values, and far range cases. Reserved raw fields are checked
separately: binary64's unused low word is zero, extended80's high word fits
16 bits, and unary second-operand slots are zero.

The added production witnesses include 32 immediate neighbors around four
negative lgamma roots in every layout, using fixed certified root brackets;
192 neighbors on both sides of nonzero pi/2 and odd-pi/4 seams; 32 immediate
neighbors of the error transition at positive and negative 16; and 60 gamma
range, minimum-normal, and zero/subnormal transition neighbors. Four further
dyadic gamma inputs exercise finite-max/overflow edges (and the distinct DD
far-overflow range). Input recipes
are independent of the numerical answer manifest and candidate output.
Gamma input seeds are regenerated by directed 4096-bit log|Gamma| inversion,
with independent 8192-bit mpmath endpoint signs. Pole search and bisection have
explicit bounds; huge Gamma values are never constructed during inversion.

The hyperbolic overflow input transitions are independently reconstructed
with positive rational-series bounds for log(2L), where L is the actual finite
maximum. The inverse thresholds asinh(L) and acosh(L) differ from log(2L) by
less than 1/L^2. Directed rational input packing must select the same population
member at both endpoints; its immediate predecessor and successor supply the
transition cases. The loop refines rather than substituting an unchecked seed.

Raw classification and signs precede ordinary Fraction conversion. Signaling
or malformed operands have priority over quiet NaNs. Exact special contracts
require exact canonical bits and exact added flags. Ordinary gamma factorials
still add IX; only gamma(1), gamma(2), lgamma(1), lgamma(2) have the stated exact
identity policy. Lgamma does not modify signgam.

## Numerical and flag acceptance

Ordinary finite outputs are checked against their actual representable
predecessor and successor. DD reference neighbors use exact component sums
and variable-spacing cells, with independent empty-cell certificates. The
checker accepts the documented one-local-ULP envelope, not only the oracle's
nearest word. Sign and canonical encoding remain strict.
The selected finite exact value is independently repacked and must reproduce
both raw words. Equal DD component sums and extended80 pseudo-denormals do
not satisfy this output encoding requirement. Ordinary edge infinities must
also match the canonical packed infinity.

Underflow is determined from the **selected candidate result**: a tiny result
adds UF/IX, including DD's 2^-969 minimum normal threshold; a normal result adds
IX. Positive controls demonstrate that valid adjacent answers on either side
of minimum normal are accepted with their respective flags, and that wrong
or extra flags reject. An interval that crosses zero does not erase signed-zero
requirements. All incoming standard flags must survive, with no unexpected
added flags.

Overflow references distinguish three ranges. Inside the finite range, the
selected result must be finite. Beyond the virtual next value above the finite
maximum, it must overflow. At the intervening edge, a selected finite maximum
is checked against that exact virtual one-ULP endpoint; a selected infinity
requires the true enclosure beyond the finite limit and adds OF/IX. This avoids
silently treating an infinite neighbor as an unlimited error allowance or
imposing global correct rounding at a seam.

Huge gamma outputs are never converted to enormous integer powers. Positive
monotonicity and 4095!>2^18000 prove far overflow. For a large representable
negative noninteger, reflection, distance>=2^-1074 from an integer and
|sin(pi*x)|>=2*distance prove a tiny interval below one quarter of the smallest
output quantum. Its sign is derived exactly from the pole parity. This tiny
contract retains the one-local-ULP rule instead of requiring an exact zero.

Outputs must also be invariant across caller modes, precision controls, and
supported FTZ/DAZ settings. Two adjacent outputs may each satisfy the numerical
envelope separately; changing between them with the caller's controls rejects.
The raw adapter and separately linked public wrapper must select identical
bits. Public native80 calls retain argument bytes until classification.

## Default and independent gates

`make check-long-double-seventeen` authenticates committed references, executes
all raw cells and all native-layout public wrappers, checks ABI objects/caller
relocations, checks the root registry, and runs the unit binary. 24 ordinary,
nonidentity state representatives per API cover every RC, supported PC,
separately seeded standard flag and supported FTZ/DAZ profile. These are compact
rotations, not a claim that the entire Cartesian product ran. Targeted
tininess/normal-boundary/overflow witnesses additionally run under each
supported flush profile, both unseeded and with incoming DZ. The optional
`check-long-double-seventeen-state-focused` uses 48 representatives per API,
covering each RC/PC pair under each supported profile. The inexpensive identity
setup grid covers the full native control product separately.
Compact quiet/signaling-NaN, malformed, domain, and pole representatives also
run with nonbaseline rounding and seeded flags. Boundary selection keeps
finite transition sides, overflow transition sides, true edge enclosures, and
far overflow in separate groups, so a far-range row cannot displace a seam.

`check-long-double-seventeen-controls` demonstrates intended-assertion rejection
of compiled numerical, incoming-flag, mode-dependent adjacent-output and ABI
faults, after positive controls. Processes must execute normally for numerical
or state detection; compile errors, crashes and timeouts do not count. It also
checks failed/false-success environment setup, malformed records, population
omission/substitution, reserved fields, exact contracts, provenance/pins,
optimized Python, read races, short reads, and short writes. Existing or partial
files are never repaired by loaders or exclusive writers.

Default gates require no container engine or host numerical oracle. There is no
expanded numerical cache: `prepare-corpora` authenticates the compact immutable
references and constant-header pin without changing files. Missing/corrupt
committed references fail closed. SDK, install and libver generation remain
independent of test preparation.

The separate `check-long-double-seventeen-oracle` requires the pinned external
instrument, regenerates the full numerical corpus and root registry, checks
fully repinned bad numerical answers and numerically valid substituted inputs,
and verifies all rational constants. `validate-long-double-seventeen-host`
runs that preflight first and only then invokes the default suite. Pins protect
normal file use; required independent regeneration establishes reference truth
and does not claim to authenticate arbitrary checker-source changes.
